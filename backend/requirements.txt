# Core serving stack. This is the only file the README asks you to install,
# and it must resolve cleanly on Python 3.10-3.13.
#
# Pins are floors, not exact versions. Exact pins broke on Python 3.13 -- e.g.
# onnxruntime 1.20.1 ships no cp313 wheel, so `pip install` failed on the dev
# machine this project targets. Floors let pip pick a build that exists for
# your interpreter while still excluding versions with APIs we do not use.
#
# Everything else the system can use -- ChromaDB, LangGraph, XGBoost, SHAP --
# lives in requirements-extras.txt because the code has a documented, tested
# fallback for each. A failure there must not block the core install.
